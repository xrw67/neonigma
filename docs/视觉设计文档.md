# 《霓虹密码机 Neonigma》视觉设计文档

版本 v2.0 · 2026-10-02 · M2 暖色纸面规范

## 1. 定位

当前 iOS 与本文档是视觉真源。旧 design/ 静态稿已删除,霓虹辉光方向已废止。界面固定浅色,使用原创暖色纸面、柔和纯色色块和粗体文字。所有 token 在 Neonigma/Theme.swift 维护。

关卡不设星级,不提供色盲辅助。保留 VoiceOver、减少动态效果和大触控区域。无外部字体、图像或第三方 UI 依赖。

- 调色盘视觉 40pt,每项热区 44×44pt。单格支持点选、长按清空、短按住后上下滑动循环颜色;普通拖动滚动棋盘,辅助功能提供相应动作。
- 主按钮珊瑚橙底深色字,次按钮暖灰底;圆角 8pt、最小高度 52pt,文字可换行。禁用主按钮用次级面板色。

- 标题/正文使用系统动态字体,关卡格编号使用等宽字体。导航按钮至少 44pt。

## 3. 页面

### 首页与选关

首页静态四色 logo、中文标题和 NEONIGMA;入口为开始/继续闯关、简单闯关、进阶闯关、双人对战、每日挑战。卡片仅标题、图标和箭头,每日挑战显示“即将推出”。设置入口位于右上。

简单/进阶选关为独立页面,无模式切换。简单显示 E1–E100 五列网格;进阶按 50 关折叠为 10 章,使用“第 1 章 · A001–A050”等标题。奶油色关卡格置于暖灰容器中,已通关用勾选标记,当前存档用书签与深棕描边。所有关卡可直接进入,替换未完成存档需确认。

### 对局

导航 → 模式/次数 → 进阶图例 → 七行棋盘 → 调色盘 → 清空/确认。棋盘顶部排列、最大宽 390pt,每行固定行号26pt、四列206pt和提示41pt,统一对齐。单人第一行标“线索”,双人无起始线索。编辑行深棕描边,未来行暖灰空槽。

棋盘独立滚动并跟随当前行,底部操作固定。手机小屏与 iPad 使用同一组件,大屏内容居中。对局返回与重开分别确认;动画期间禁止编辑。

### 单人结算

奶油白弹层可滚动,支持中/大高度。成功显示结果、猜测次数、有效用时和答案,提供下一关/重玩/选关;模式末关改为返回选关。失败显示重试/选关及受设置控制的查看答案入口,默认不自动揭示。无星级。

### 双人

出题页显示当前出题者、提示模式、四色密码编辑区、限时菜单和交接按钮。重复颜色显示错误文案并禁止交接;Reduce Motion 关闭时可轻微抖动。

交接页为完全不透明遮罩,只有交接说明和开始按钮。后台时出题、棋盘与结果均遮挡且不可被 VoiceOver 访问;返回需点击继续。破译页显示倒计时或“不限时”,最后30秒使用危险色并每秒轻触觉。

结算显示答案、双方比分、用时和剩余时间,提供换边再来/返回主菜单。双方身份为玩家1/玩家2。

### 教程与设置

首次教程为可滚动的三步互动页,顶部有进度与跳过:点格选色、提交并理解三态、根据 E001 教学提示破译。首次完成进入 E002;设置重放不覆盖存档。首次进入任何进阶关卡显示固定2×2的图解页。

设置为系统浅色表单,包含音效、触觉、失败后允许查看答案、重放教程及离线关于/隐私文本;M2 不展示英语和统计页入口。

## 4. 反馈与可访问性

- 提示逐点揭示约360ms,期间冻结编辑;规则结果不等待动画,退出/重开/后台切换可取消动画并完整显示反馈。
- 成功播放最多2秒的 SwiftUI Canvas 彩带。Reduce Motion 下取消彩带、抖动与非必要提示动画。
- 七色按钮朗读颜色,编辑格朗读行列、颜色和选中状态;直接提示逐格朗读,间接提示朗读对位/错位个数。遮罩下内容隐藏于辅助功能树。
- 音效与触觉分别遵守设置;真机静音键、触觉及 VoiceOver 完整流程需手工验收。
- 保存失败以可重试的顶部提示展示;加载失败显示保留数据的错误页,不静默清除存档。
