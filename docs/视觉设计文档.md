## 1. 文档定位

- 本文档是 `design/` 视觉稿的**文字化规范**,供 SwiftUI 实现、后续迭代与 AI 协作使用;
- 冲突裁决:**视觉效果以 `design/index.html` 渲染结果为准,数值规格以本文档表格为准**;两者不一致时先修文档或稿,再动代码;
- 所有 token 与 `design/css/tokens.css` 一一对应,变量名保持一致,方便直接映射 SwiftUI;
- 预览方式:双击 `design/index.html` 离线打开;或 `cd design && python3 -m http.server` 后访问 `http://127.0.0.1:8000`。

## 2. 设计方向

**Style A「霓虹灯珠 · 复古电子风」**(2026-10-01 定稿):

- 意象:复古电子解谜机——**深炭黑哑光底板 + 发光圆角色珠(灯珠)+ 灯箱辉光 + 街机机械感**;
- 调性:儿童可亲、成年不觉幼稚;亮色只来自「有信息的东西」(色珠、提示点、LED),界面骨架保持克制;
- 合规红线(PRD §1.3):**不复刻原型机机身造型与 UI 布局**,整体视觉为原创演绎,规避 trade dress 风险;
- 章节主题方向:简单 = 暖色时段,进阶 = 霓虹夜色(具体章节命名待定,例:「城市灯火」)。

## 4. 组件规范

### 4.1 色珠 `.peg`(核心资产)

| 状态 | 视觉 | 实现 |
|---|---|---|
| 空槽 | 凹槽底 + 内阴影 + 1.5px 微亮描边 | `--well` + `--inset-well` 变体 |
| 填充 | 三值径向渐变 + 外辉光 + 顶部釉面高光 | `.pc-*` 类注入 4 个 CSS 变量 |
| 选中 | 琥珀描边 2.5px(offset 3px)+ 呼吸辉光 | `selPulse 1.6s` 无限循环 |
| 压暗 | 去饱和降亮 | `saturate(.55) brightness(.62)`,结算背景棋盘用 |
| 幽灵 | 半透明 | `opacity:.5`,未到达的空行 |
| 色盲符号 | 右下角 10px 水印 | `.sym`,黑 50% + 白色微投影,开关控制 |

### 4.2 提示点 `.hdot`

9px 圆点(图例内 8px);三态见 3.2;点亮时 `dotPop` 弹入动画(0.35s,scale .3→1.25→1)。

### 4.3 直接提示行 `.dhints`(简单模式)

- 位置:**行下方**,4 个 `.slot` 每个宽 44px 居中,**与棋盘四列严格对齐**(逐格对应是玩法语义,不可错位);
- 内容:每槽一枚三态提示点,对应该列颜色判定;
- 生成后随提交动画逐点点亮(间隔 90ms)。

### 4.4 间接提示徽章 `.ibadge`(进阶模式)★ 2026-10-01 定稿

- 位置:行**右侧**垂直居中;
- 形状:**固定 2×2 网格**(格 9px、间距 5px、内边距 8px),成品约 **41×41 正方形**,不随点数变化;
- 填充顺序:**绿点先、白点后**,按行主序(左→右、上→下)填充;例:2绿2白 = 上排两绿下排两白;1绿3白 = 绿白 / 白;
- 底:`--panel-2` + `--line` 描边 + 内凹阴影(与凹槽语言一致);
- 当前编辑行以低透明度(约 .5)显示 **4 个灭点占位**,提示 2×2 槽位形状;
- 设计依据:与经典 Mastermind 边钉及原型机行侧灯位一致;宽度恒定,给棋盘让出最大宽度;点数即计数,一眼读出"x/4"。

### 4.5 行 `.rowwrap` 四类型

| 类型 | 标识 | 视觉 |
|---|---|---|
| 线索行 | `.clue` | 蓝色系:边框 `rgba(0,145,255,.18)` + 5% 蓝底;rowtag 用 `--c-blue-hi`;「第 1 行 · 起始线索」 |
| 当前行 | `.current` | 琥珀系:边框 `rgba(255,178,36,.22)` + 5% 琥珀底;rowtag 用 `--amber`;「第 N 行 · 编辑中」 |
| 已提交行 | 无 | 无底色,锁定态 |
| 幽灵行 | `.ghosted` | 半透明空珠,表示剩余机会 |

`.rows` 容器**底部对齐**(`justify-content: flex-end`),行距 9px,列内珠距 10px;rowtag 10px 字号。棋盘满 7 行时自动向上生长。

### 4.6 按钮

| 变体 | 规格 | 视觉 |
|---|---|---|
| `btn-primary` | 高 52 / r14 | 琥珀三段纵向渐变 + 深棕文字 `#1A1204` + 外辉光 + 顶部内高光;禁用态灰化降亮(灰度 .85 / 亮度 .5) |
| `btn-ghost` | 同上 | `--panel` 底 + `--line` 描边 + `--text-2` 文字 |
| `btn slim` | 高 48 | 定宽变体(如「↻ 重新开始」) |
| `icobtn` | 36×36 / r12 | 面板底描边小方钮;`.accent` 琥珀字色(重开/静音) |

按钮文字:`--font-round` 800 字重、16px、字距 .06em;按压 `scale(.97)`(主按钮)/ `scale(.9)`(调色盘珠)。

### 4.7 调色盘 `.palette`

7 枚 40px/r11 色珠横排居中、间距 9px;点击即向选中格填色;**不可用色不减淡**(游玩中 7 色始终可选,由规则引擎负责判重提示)。

### 4.8 LED 数字屏 `.led`

等宽字体 + `--amber` + 深底 `#0A0D12` + 双层阴影(内暗 + 微外辉),字距 .14em;`.sm` 小号(比分、星数、状态);`.danger` 红色变体(**双人倒计时最后 30 秒**切换,PRD FR-D3)。

### 4.9 屏内骨架

- `navbar` 高 46:左 `‹` 返回 | 中 LED(关卡号或倒计时)| 右动作钮(↻ 重开 / ♪ 静音);
- `chipline` 12px 两端对齐:模式名 + 「已用 n/6 次」;
- `legend` 11px:三态图例,随模式切换文案(直接:对色对位/对色错位/不存在;间接:对位个数/错位个数/只报数量·不报位置)。

### 4.10 开关与分段

- `toggle`:iOS 风格 50×30,开启色用 `--hint-on`(复用提示绿的"正确/开启"语义);
- `seg`:凹槽底 r12 + 选中块 `--panel-2` 浮起;选关页大号(简单/进阶)、出题页限时档 5 段小号。

### 4.11 关卡格与星级

- `lvgrid`:**每行 5 格**、间距 9、正方形 r13;
- 三态:未玩(默认)/ `done`(文字提亮)/ `now`(**琥珀渐变底 + 深棕字 + 外辉光**,唯一发光格);
- 格内:LED 字体关卡号(如 E21)+ 9px 三星;
- 星级 `--star` `#FFC53D`,亮星带辉光,灭星 `--hint-off`。

### 4.12 卡片 / 列表 / 进度条

- `card`:`--panel` + `--line-soft` + r18 + `--shadow-panel`;
- `list`:分组列表,首尾圆角 14、相邻共边;`ico` 30×30 方形图标位;`.end` 右侧值区;
- `progressbar` 6px:底 `--well`,填充**蓝→紫渐变 + 蓝辉光**(章节进度语言)。

### 4.13 弹层与彩带

- `overlay`:全屏遮罩 `rgba(5,8,12,.5)` + 背景 4px 毛玻璃;
- `sheet`:底部弹出,r24 顶部圆角,深灰渐变底(`#1A202A→#12161D`)+ 顶部 1px 亮线;入场 `sheetUp .4s` 回弹曲线;
- `stars-big` 34px,三颗星**依次弹入**(延迟 .1/.28/.46s,`starIn` 缩放旋转);
- `confetti`:8×13px 七色纸片自顶飘落(2.2–3.8s 随机),仅破译成功。

### 4.14 主菜单组件

- `menuhero`:4 枚 34px logo 色珠**浮动循环**(bob 2.6s,错峰 .2s)+ 34px 圆体标题「霓虹密码机」+ 等宽小字 NEONIGMA(字距 .5em);
- `modecard`:46px 彩色图标位 + 标题/副文 + 右箭头;**模式色相区分:蓝=继续闯关(带进度条)、绿=单人、紫=双人、琥珀=每日**;「继续闯关」加蓝紫渐变底纹与描边,是第一视觉入口。

### 4.15 教程层

遮罩 `rgba(6,9,14,.78)` 压暗全局;目标行 `tuttarget` 琥珀 3px 描边 + 34px 大辉光 + 呼吸;底部讲解卡(pips 步数条 18×5,当前步琥珀);右上「跳过」。

### 4.16 统计组件

## 7. 动效规范

| 动效 | 参数 | 触发 |
|---|---|---|
| 选中呼吸 `selPulse` | 1.6s ease-in-out 无限 | 选中格 / 教程目标行 |
| 调色盘按压 | scale .9 / .15s | 按下色珠 |
| 换色 | 即时重绘(无过渡) | 上下滑动循环换色 |
| 提示逐点点亮 `dotPop` | 每点 0.35s,间隔 90ms | 提交后(直接逐格 / 间接 2×2 依填充序) |
| 行锁定 | 提交即锁定,无回弹 | 提交 |
| 弹层 `sheetUp` | .4s `cubic-bezier(.2,.9,.3,1.2)` | 结算 / 揭示答案 |
| 三星 `starIn` | 依次 .1/.28/.46s 缩放旋转弹入 | 破译成功 |
| 彩带 `confFall` | 2.2–3.8s 随机,循环飘落 | 破译成功 |
| logo 浮动 `bob` | 2.6s,错峰 .2s | 主菜单 |
| 入场淡入 | .6s 上移 18px | 设计稿画廊(游戏内可类比页面转场) |

**Reduce Motion**:遵循系统「减弱动态效果」——所有无限循环动画与入场动画停用/缩至 .01s,仅保留状态切换的透明度变化(设计稿已内建 `prefers-reduced-motion` 降级,iOS 同样处理)。

## 8. 无障碍

- **色盲辅助符号**:每色唯一几何符号 ■▲●◆★✚✿,开启后叠加在色珠右下角;要求**仅凭符号可完整游玩**(信息等价,验收 A9);
- **VoiceOver**:色珠可聚焦;直接提示朗读示例「第 3 格:颜色对,位置不对」;间接徽章朗读「对位 2 个,错位 1 个」;
- **最小点击区 ≥44pt**:色珠 44px 本身即达标;调色盘 40px 在 iOS 实现时需保证热区 ≥44;
- 提示绿 `#30D158` 与灭 `#262E3A` 的对比度满足暗底可辨;正文文字层级均达 WCAG AA(暗底浅字)。

## 9. 视觉事件 ↔ 音效/触觉(与 PRD FR-P5 / §6.3 同源)

| 视觉事件 | 音效 | 触觉 |
|---|---|---|
| 选中格 | 轻「嗒」 | light impact |
| 调色盘填色 | 咔哒(3–5 变体) | light |
| 提交行 | 铿锵 | medium |
| 提示逐点点亮 | 绿=上行单音 / 白=中音 / 灭=静默 | 逐点 light |
| 破译成功 | 8–12 音符上行旋律 + 彩带 | success notification |
| 失败 / 超时 | 2 音下行 | error notification |
| 倒计时最后 30s | 心跳提示音(与 LED 变红同步) | 心跳节律 |

规则:**触觉与音效同源触发**,保证「手感」一致;全部可关(设置)。

## 10. SwiftUI 映射指南

- 颜色:七色 × 4 值 + 提示三态 + 层级色全部进 Asset Catalog,命名沿用变量(如 `c-red`、`c-red-hi`、`hint-on`),dark-only;
- 色珠:`RoundedRectangle(cornerRadius: 12)` + `RadialGradient`(锚点 30%,18%)+ `shadow(color: glow, radius: 16)`;空槽用 `LinearGradient` 内阴影或 overlay;
- 2×2 徽章:`Grid` 固定 2×2,槽位预置 4 枚 `Circle`(9pt/间距 5),按「绿先白后、行主序」点亮——槽位常驻,不要按需增删,保持形状恒定;
- 直接提示:`LazyVGrid(columns: 4 × 44pt)` 与棋盘共用列定义,保证对齐;
- LED 数字屏:系统等宽数字 + 琥珀 + `shadow(radius: 10)` 模拟辉光,无需自定义字体;
- 动效:`scaleEffect` + `animation(.spring)` 对应 dotPop/sheetUp;`@Environment(\.accessibilityReduceMotion)` 统一降级;
- **行为基准**:交互与判定逻辑以 `design/js/demo.js` 为准(evaluate 与 PRD §3.4 严格一致)。
